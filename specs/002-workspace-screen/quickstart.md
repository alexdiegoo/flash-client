# Quickstart: Workspace Screen

## Prerequisites
- Node.js (Latest LTS)
- Electron (Included in dev dependencies)

## Running the Homepage
1.  **Launch the application**:
    ```bash
    npm run dev
    ```
2.  **Verify the list**:
    - The app should open the homepage.
    - If no workspaces exist, you should see an empty state message.
3.  **Create a new workspace**:
    - Click the "Create New Workspace" button.
    - Confirm the redirection to the creation flow.

## Testing
- **Unit tests**: `npm run test:unit`
- **E2E tests**: `npm run test:e2e` (Requires Playwright)
