# Flash Client

A modern desktop application built with Electron, React, Tailwind CSS v4, and Shadcn UI.

## Features
- Perfectly centered "hello world" greeting.
- Dynamic resizing.
- Built-in E2E and Unit testing.

## Getting Started

### Prerequisites
- Node.js (Latest LTS)

### Installation
```bash
npm install
```

### Development
To start the application in development mode:
```bash
npm run dev
```

### Building
To build the application for production:
```bash
npm run build
```

### Testing
- **Unit Tests**: `npm run test:unit`
- **E2E Tests**: `npm run test:e2e`
